# Game Day Board

**Status: work in progress (Milestone 0, setup). Nothing is deployed yet.**

Game Day Board will show this week's college football games and scores for the Big 12 and the SEC, with a page for each team. It is a learning and portfolio project with a Go back end, a React front end, and Google Cloud hosting.

This README describes only what is built. It will grow as each milestone is finished.

- How the project was built, step by step: [docs/BUILD-GUIDE.md](docs/BUILD-GUIDE.md)

Data provided by [CollegeFootballData.com](https://collegefootballdata.com).
